# Temple Heritage — AI Pilgrimage Explorer

A modern, original temple discovery and pilgrimage-planning web app inspired by the visual direction you provided.

## Features in this starter
- Heritage-style homepage
- Temple directory with search and filters
- Individual temple detail pages
- Festival calendar
- Interactive-looking AI Yatra Planner UI
- Rule-based temple recommender (ready to connect to ML/LLM later)
- Temple AI assistant demo UI
- Responsive navbar and mobile menu
- Reusable components and centralized temple data

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
